## 📖 About

**Bee Mastery** is a comprehensive apiculture expansion mod for **Forestry: Community Edition**, bringing 11 unique bee species, advanced equipment, and powerful resources to your Minecraft world.

> **🌟 Spiritual Successor:** This mod is a continuation of the beloved **ForestryExtras** by wasliebob, completely rebuilt for modern Minecraft while preserving the original vision and textures. We've expanded upon the foundation with new features and improvements for the 1.20.1+ era.

Whether you're breeding agricultural bees for crops, livestock bees for resources, or pursuing the legendary tier for ultimate power, Bee Mastery offers a complete progression system from humble beginnings to apicultural supremacy.

## ✨ Features

### 🐝 New Bee Species
Discover **11 unique bee species**, each with special properties and products:

| Bee Species | Primary Product | Special Traits |
|------------|----------------|----------------|
| 🥔 **Potato** | Potato, Poisonous Potato | Agricultural bee |
| 🥕 **Carrot** | Carrot, Golden Carrot | Agricultural bee |
| 🐷 **Pig** | Porkchop | Livestock bee |
| 🐄 **Cow** | Leather, Beef | Livestock bee |
| 🐑 **Sheep** | Wool, String | Livestock bee |
| 🏺 **Clayious** | Clay Ball | Resource bee |
| 🛡️ **Reinforced** | Reinforced Nugget | Advanced bee |
| ⚗️ **Mutated** | Mutated Iron Nugget | Mutation specialist |
| 💀 **Witheria** | Witheria Nugget | Nether bee |
| 🐉 **Draconic** | Draconic Nugget | Elite bee |
| 👑 **Legendary** | Legendary Nugget | Ultimate bee |

### 🔧 Items & Blocks

#### **Ingots & Materials**
- 🔴 **Draconic Ingot** - Forged from dragon essence
- 🔵 **Legendary Ingot** - The ultimate material
- ⚪ **Reinforced Ingot** - Enhanced durability
- ⚫ **Witheria Ingot** - Infused with wither power
- 🟢 **Mutated Iron** - Genetically enhanced iron

#### **Advanced Tools**
- 🥅 **Scoops** (Reinforced, Draconic, Legendary)
  - Faster hive breaking
  - Increased durability (300-10,000 uses)
  - Catch vanilla bees
- 🌿 **Grafters** (Reinforced, Draconic, Legendary)
  - Enhanced sapling drop rates (3x-10x)
  - Long-lasting durability

#### **Bee Frames**
10 unique frame types with different modifiers:
- 🪵 Coal, Iron, Gold, Diamond, Emerald
- 🛡️ Reinforced, Witheria, Draconic
- 🧬 Mutation (10x mutation chance!)
- 👑 Legendary (5x production!)

#### **Colored Propolis**
5 types of propolis with enchantment glints:
- Reinforced, Witheria, Mutated, Draconic, Legendary

## 📦 Installation

1. **Download & Install Prerequisites:**
   - [Minecraft Forge 47.2.0+](https://files.minecraftforge.net/net/minecraftforge/forge/index_1.20.1.html)
   - [Forestry: Community Edition 7.0.0+](https://www.curseforge.com/minecraft/mc-mods/forestry-community-edition)

2. **Install ForestryExtras CE:**
   - Download the latest release from [Releases](../../releases)
   - Place the `.jar` file in your `mods` folder
   - Launch Minecraft with Forge

3. **Start Playing!**
   - Find wild bee hives
   - Breed new species
   - Craft powerful equipment

## 🧬 Recipes

### Bee Mutations

All custom bees can be bred through specific parent combinations:

```
Forest + Meadows → Potato (15%)
Forest + Meadows → Carrot (15%)
Steadfast + Carrot → Pig (30%)
Steadfast + Potato → Cow (30%)
Carrot + Potato → Sheep (30%)
Meadows + Noble → Clayious (15%)
Valiant + Noble → Reinforced (5%)
Majestic + Reinforced → Mutated (5%)
Industrious + Mutated → Witheria (5%)
Witheria + Reinforced → Draconic (5%)
Witheria + Draconic → Legendary (5%)
```

### Centrifuge Products

Process combs in a centrifuge to extract valuable resources:

| Comb | Products | Chance |
|------|----------|--------|
| Draconic | Draconic Nugget | 10% |
| Legendary | Legendary Nugget | 5% |
| Reinforced | Reinforced Nugget | 25% |
| Witheria | Witheria Nugget | 15% |
| Mutated | Mutated Iron Nugget | 15% |
| Clayious | Clay Ball | 15% |
| Potato | Potato, Poisonous Potato | 15% each |
| Carrot | Carrot, Golden Carrot | 15%, 2% |
| Pig | Porkchop | 15% |
| Cow | Leather, Beef | 10%, 15% |
| Sheep | Wool, String | 10%, 15% |

## 🛠️ Development

### Building from Source

```bash
git clone https://github.com/eliasnvx/BeeMastery.git
cd BeeMastery
./gradlew build
```

The compiled `.jar` will be in `build/libs/`

### Requirements
- Java 21
- Gradle 8.8
- Minecraft 1.20.1
- Forge 47.2.0+
- Forestry CE 7.0.0+
