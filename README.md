ForestryExtras CE
==============

Forestry Extras ported to Minecraft 1.20.1+ with Community Edition Forestry support.

## Description

This mod adds extra bees, items, and blocks for Forestry: Community Edition.

## Features

- 11 new bee species (Draconic, Legendary, Reinforced, Witheria, Mutated, Clayious, Pig, Cow, Sheep, Potato, Carrot)
- New ingots and items
- New blocks
- Original textures preserved

## Development

This is a port of the original ForestryExtras mod for modern Minecraft versions.

### Requirements

- Minecraft 1.20.1
- Forge 47.2.0+
- Forestry: Community Edition 7.0.0+
